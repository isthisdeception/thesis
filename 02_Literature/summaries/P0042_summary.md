# Paper Summary: P0042

## Metadata
- **Paper ID:** P0042
- **Title:** FakeLocator: Robust Localization of GAN-Based Face Manipulations
- **Authors:** Yihao Huang, Felix Juefei-Xu, Qing Guo, Yang Liu, Geguang Pu
- **Year:** 2022
- **Venue:** IEEE Transactions on Information Forensics and Security (DOI: 10.1109/tifs.2022.3141262; arXiv:2001.09598v4)
- **DOI:** 10.1109/tifs.2022.3141262

## Problem
While many DeepFake detectors perform binary real/fake image classification, they rarely pinpoint *where* a facial image was manipulated—especially for subtle attribute edits (e.g., hair color, smile, eyeglasses) rather than large face-swaps. Existing localization methods either output coarse low-resolution attention maps (e.g., $19\times 19$ for $299\times 299$ input in Dang et al. [27]), rely solely on local patch receptive fields (Chai et al. [30]), or fail on entirely synthetic faces (Face X-ray [42]). Furthermore, binary ground-truth fakeness maps depend on subjective thresholds that discard weak manipulation signals. There is a need for a **full-resolution, degradation-robust, cross-attribute and cross-method universal** face forgery localization pipeline.

## Motivation
The authors inspect the official implementations of seven SOTA GAN-based face generators (IcGAN, AttGAN, StarGAN, STGAN, PGGAN, StyleGAN, StyleGAN2) and observe that all GAN decoders rely on upsampling operations—specifically transposed convolution (6 of 7 GANs) or interpolation (IcGAN), alongside unpooling in general architectures. All three upsampling mechanisms introduce characteristic **fake textures** (checkerboard patterns or second-derivative periodicity) absent in real camera images. Modeling these upsampling-induced fake textures with a continuous **gray-scale fakeness map** preserves fine-grained spatial manipulation intensity and enables simultaneous detection and full-resolution localization.

## Method
The **FakeLocator** framework (Section IV, Fig. 5) comprises five core components:
1. **Gray-Scale Fakeness Ground Truth & Regression Loss** (Section IV-E, Eq. 6–12, Fig. 10–11): Replaces thresholded binary masks with continuous gray-scale maps $M_{GT\_G} \in [0, 1]^{H\times W\times 1}$—set to all $0$ for real images, all $1$ for entire face synthesis, and $M_{GT\_G_{i,j}} = \text{Gray}(|X_{i,j,k} - X'_{i,j,k}|)/255$ for partial face manipulations. Compares $L_1$, $L_2$, Focal, and Dice losses, selecting **$L_1$ regression loss** to avoid threshold instability.
2. **Encoder-Decoder Localization + Joint Classification Branch** (Section IV-B, Eq. 2–4): Predicts $M_{Pred} = \mathcal{F}_{dec}(\mathcal{F}_{enc}(X'))$ with a Sigmoid limiting layer constraining intermediate/output features to $[0,1]$, paired with an auxiliary binary classifier $y_{pred} = \mathcal{C}(\mathcal{F}_{enc}(X'))$ trained jointly via cross-entropy loss.
3. **Face-Aware Attentional Encoder-Decoder (Face Parsing Module)** (Section IV-C, Eq. 5, Fig. 5–7): Because GANs use skip connections to repair pixels outside the edited attribute (diluting fake textures there), a Face Parsing Module (FPM) extracts the modified attribute mask during training, expands it via a blur filter $\text{Blur}(\text{FPM}(X', p))$, and channel-wise multiplies it with encoder feature maps. During testing, a uniform white map is fed instead so no prior attribute label is needed.
4. **Partial Data Augmentation** (Section IV-D): Applies data augmentation **exclusively to real training images** (`real(1.0)fake(0.0)`) so the model learns the broadest real-image distribution without corrupting delicate fake textures.
5. **Single Sample Clustering** (Section IV-D, Fig. 8–9): For severe cross-type shifts (e.g., identity swap $\leftrightarrow$ attribute manipulation / entire synthesis), reduces encoder features via t-SNE, clusters them into 2 clusters via k-means without labels, and assigns real/fake cluster identity using **one labeled sample** from the unknown target GAN.

## Architecture
- **Localization Backbone:** Pre-trained PyTorch **DeepLabv3-ResNet101** (initialized from COCO train2017 / 20 Pascal VOC categories), fine-tuned with a Sigmoid limiting layer; input/output spatial resolution fixed at $224 \times 224$ (Section V-A).
- **Classification Branch $\mathcal{C}(\cdot)$:** 4 convolutional layers ($3\times 3$ kernel), 1 max-pooling layer ($2\times 2$ kernel, stride 2, padding 0), 3 fully connected layers, and a Sigmoid output layer (Section V-A).
- **Code & Custom Dataset Availability:** Not reported in the paper (no public repository or custom-dataset URL provided).

## Dataset
- **Real Face Databases (Section V-A):** **CelebA** (202,599 images, 40 binary attributes) and **FFHQ** (70,000 high-quality images).
- **Custom 7-GAN PNG Dataset (Table II):** High-resolution PNG images generated by **STGAN** (9 properties, CelebA), **AttGAN** (8 properties, CelebA), **StarGAN** (5 properties, CelebA), **IcGAN** (4 properties, CelebA), **StyleGAN** (Smile, Age, Gender + Entire, FFHQ), **PGGAN** (Entire, FFHQ), and **StyleGAN2** (Entire, FFHQ). For the universal model (Table IX), 64,000 fake images (2,000 per GAN-property pair) and 64,000 real images are sampled.
- **Public DeepFake Benchmarks (Section V-A, V-B):** **UADFV** (28,000 train / 2,000 test), **Celeb-DF** (280,000 train / 20,000 test), **DFFD** (12,618 / 39,914 / 43,698 / 39,998 train images for faceapp / PGGAN / StarGAN / StyleGAN; 9,000 test each), and **FaceForensics++** (180,000 train / 18,000 test for identity swap).

## Training
- **Hardware & Environment:** Ubuntu 16.04, Intel Xeon E5-2699 CPU, 196 GB RAM, NVIDIA Tesla V100 (32 GB) (Section V-A).
- **Hyperparameters:** 10 epochs, Adam optimizer ($\alpha = 0.0001, \beta_1 = 0.99, \beta_2 = 0.999$, weight decay $= 10^{-7}$), minibatch size 8, all inputs resized to $224 \times 224$ (Section V-A).

## Evaluation
- **Classification Metrics:** ACC, real ACC, fake ACC, EER, AUC (Section V-A).
- **Localization Metrics:** Continuous similarity metrics **COSS** (cosine similarity), **PSNR**, **SSIM**; plus thresholded (0.1) binary overlap metrics **IoU**, **Dice**, **PBCA** (pixel-wise binary classification accuracy), and **IINC** (inverse intersection non-containment, lower is better).
- **Protocols:**
  1. Detection vs CNNDetection [13] and DCTA [26] on UADFV & Celeb-DF (Table III).
  2. Loss ablation ($L_1$, $L_2$, Dice, Focal, and `no cl`) on STGAN (Bald) vs Dang et al. [27] (Table IV).
  3. Localization & detection vs Dang et al. [27] and Chai et al. [30] on DFFD and FaceForensics++ (Table V).
  4. Cross-attribute, cross-GAN, partial augmentation, single-sample clustering, and face-parsing ablations (Tables I, VI–X).
  5. Robustness against 4-piece spatial **disorganization** (Fig. 13–14) and 4 **real-world degradations** on 1,000 fake images: JPEG compression (Q 100$\to$10), Gaussian blur (kernel 3$\to$19), Gaussian noise (variance 0$\to$40), and linear low-resolution resizing (reduction ratio 0$\to$32) (Fig. 15).

## Results
- **Detection vs SOTA (Table III):** Matches CNNDetection on **UADFV** (**1.0000 ACC**, beating DCTA's 0.8560) and achieves **0.9304 ACC** on **Celeb-DF** (real ACC 0.8560, fake ACC 0.9977; beating DCTA's 0.5800 but below CNNDetection's 0.9992).
- **Localization vs Baselines (Table V):** Outperforms Dang et al. [27] and Chai et al. [30] across almost all localization metrics on DFFD and FF++:
  - *DFFD (StarGAN):* **COSS 0.8373, PSNR 19.39, SSIM 0.6433, IoU 0.4953, IINC 0.2551** (vs [27] IoU 0.0345; [30] IoU 0.3887).
  - *DFFD (PGGAN):* **ACC 1.0, COSS 1.0, PSNR 142.8, SSIM 0.9999, IoU 1.0, IINC 0**.
  - *DFFD (StyleGAN):* **ACC 0.9998, COSS 0.9998, PSNR 127.3, SSIM 0.9997, IoU 0.9998, IINC 0.0001**.
  - *DFFD (faceapp):* **ACC 0.9998, COSS 0.7250, PSNR 23.11, SSIM 0.6550, IoU 0.2384** (though EER 0.2355 is worse than [27] 0 and [30] 0.0020).
  - *FaceForensics++:* **ACC 0.9398, AUC 0.9846, EER 0.0576, COSS 0.7529, PSNR 26.94, SSIM 0.7691, IoU 0.3097, PBCA 0.8687, IINC 0.3143** (beats [27] AUC 0.8714 and [30] AUC 0.4659).
- **Cross-Method Partial Augmentation + Single-Sample Clustering (Table I):** FF++ $\to$ StarGAN / StyleGAN / PGGAN improves from **0.490 / 0.363 / 0.369** (no aug) to **0.988 / 0.500 / 0.500** (partial aug) to **0.999 / 0.854 / 0.975** (+ single-sample clustering). Reverse transfer (StarGAN / StyleGAN / PGGAN $\to$ FF++) improves from **0.425 / 0.452 / 0.448** to **0.817 / 0.817 / 0.676**.
- **Cross-Attribute Face Parsing (Table X):** Training on STGAN (Blond hair) and testing on unseen Black hair / Brown hair / Smile boosts ACC from **0.237 / 0.588 / 0.448** (no FP) to **0.670 / 0.859 / 0.752** (with FP).
- **Universal 7-GAN Model (Table IX):** Achieves **0.9935–0.9995 ACC** across all partial attribute manipulations, **0.9775** on PGGAN Entire, **0.9210** on StyleGAN Entire, and **0.8550** on StyleGAN2 Entire, with COSS **0.7365–0.9972**.
- **Degradation & Disorganization Robustness (Fig. 13–15):** Maintains strong stability under 4-piece spatial scrambling (location independence) and under moderate JPEG compression, Gaussian blur, Gaussian noise, and downsampling, degrading mainly under extreme noise/compression or severe low-resolution resizing.

## Strengths
- **Full-resolution continuous localization:** Gray-scale fakeness maps with $L_1$ regression overcome the coarse $19\times 19$ maps of [27] and subjective thresholding of binary forgery masks.
- **Grounded in generator mechanics:** Explicitly ties localization signal to GAN upsampling artifacts (transposed convolution, interpolation, unpooling).
- **Effective cross-attribute & cross-method tricks:** Training-time face-parsing attention (with a label-free white map at inference) and real-only partial data augmentation meaningfully reduce overfitting to attribute locations and single-GAN distributions.
- **Thorough degradation evaluation:** Tests spatial disorganization plus controlled JPEG, blur, noise, and low-resolution curves.

## Weaknesses
- [GAP-ready: supported by P0042] **GAN-only / pre-diffusion paradigm:** Explicitly relies on GAN upsampling textures and is not evaluated on diffusion-generated faces; authors also acknowledge vulnerability to shallow reconstruction/anti-forensic defenses ([53], [54]).
- [GAP-ready: supported by P0042] **Paired real/fake ground-truth requirement during training:** Computing gray-scale ground-truth maps $M_{GT\_G}$ for partial manipulations (Eq. 7) requires paired original and manipulated images $(X, X')$, which do not exist for in-the-wild unpaired images.
- [GAP-ready: supported by P0042] **Single-sample clustering is non-zero-shot and batch-dependent:** Cross-type generalization (Table I) relies on t-SNE + k-means over a batch of target features plus at least one labeled sample from the unknown target generator, limiting single-image deployment.
- [GAP-ready: supported by P0042] **Low fixed input resolution ($224 \times 224$):** Resizing high-resolution faces (e.g., $1024 \times 1024$ FFHQ/StyleGAN2) down to $224 \times 224$ for DeepLabv3-ResNet101 attenuates subtle high-frequency upsampling traces—consistent with StyleGAN2 Entire dropping to 0.8550 ACC (Table IX).
- [GAP-ready: supported by P0042] **Inconsistent cross-method and Celeb-DF performance:** In Table VIII, AttGAN (Blond/Brown hair) $\to$ STGAN remains near chance (0.5015 ACC) even with partial augmentation; Celeb-DF ACC (0.9304, real ACC 0.8560) trails CNNDetection (0.9992), and DFFD (faceapp) shows elevated EER (0.2355, Table V).
- [GAP-ready: supported by P0042] **No public code or custom dataset release reported:** Reproducibility of the exact 7-GAN PNG benchmark and training pipeline is hindered by missing repository/dataset links.

## Research Gap
- [GAP-ready: supported by P0042] Pixel-level continuous fakeness localization has not been extended from GAN upsampling artifacts to **diffusion-model** inpainting and full-face synthesis traces.
- [GAP-ready: supported by P0042] Zero-shot cross-method localization without requiring target-batch clustering or a labeled target sample remains unsolved.
- [GAP-ready: supported by P0042] Native high-resolution (or patch/multi-scale) localization architectures that preserve fine-grained upsampling/denoising residuals without $224 \times 224$ downsampling are needed.

## Future Work
- Authors propose visualizing fake textures per image and classifying them by specific GAN architecture and upsampling method (source attribution, Section VI).
- Extending localization against adversarial reconstruction/anti-forensic methods ([53], [54]) and non-additive adversarial attacks ([51], [52]).
- Applying FakeLocator's gray-scale fakeness paradigm to modern diffusion-based local face edits and video deepfakes.

## Interesting Ideas
- **Real-only partial data augmentation (`real(1.0)fake(0.0)`):** Augmenting only real images expands the decision boundary of authentic camera distributions without distorting fragile synthetic upsampling artifacts—a generally transferable training trick for forensic detectors.
- **Asymmetric train/test attention:** Using Face Parsing Masks only during training to steer feature learning onto edited regions, while passing a neutral white mask at test time so inference requires zero attribute metadata.
- **Regression ($L_1$) over segmentation losses (Dice/Focal):** Treating localization as continuous artifact-strength regression rather than thresholded binary segmentation.

## Possible Reuse
- **MOD010 (Explainability Engine) & MOD003 (`explainability_input` / `texture_analysis`):** FakeLocator's gray-scale fakeness map provides an interpretable spatial localization payload (`attention_maps` / `saliency` data) pinpointing *where* partial face edits occurred, complementing scalar probabilities from MOD004.
- **MOD004 (Deep Learning Specialist):** The real-only partial data augmentation strategy (`real(1.0)fake(0.0)`) can be reused when training registered image detectors to improve cross-generator robustness without corrupting synthetic frequency/upsampling traces.
- **MOD009 (Confidence Estimation) & MOD011 (Forensic Reasoning Engine):** Continuous fakeness intensity maps allow reasoning over *localized manipulation strength* vs *global face synthesis* (all-high vs region-specific heatmaps).

## Questions
- Would replacing the $224 \times 224$ DeepLabv3-ResNet101 backbone with a space-frequency backbone like SFIConv (P0041) or high-resolution feature pyramid prevent the accuracy drop on StyleGAN2 Entire (0.8550) and high-res faces?
- Do diffusion-based face inpainting/editing models leave localized residual maps trainable via the same gray-scale $L_1$ formulation without paired $(X, X')$ ground truth?
- Why did `DFFD (faceapp)` exhibit EER = 0.2355 despite ACC = 0.9998 and AUC = 1.0 in Table V (possibly calibration/threshold shift)?
