# Decision: DEC0005

**Decision Status:** APPROVED & LOCKED (Human Ratified)
**Date:** 2026-08-01
**Supersedes:** DS0005 entry in DEC0004 (SUPPLEMENTARY-BIAS role only)

---

**Problem:** During STEP-021 re-execution, verification of dataset source URLs revealed that **DS0005 (AI-Face-FairnessBench)** — selected in DEC0004 as the SUPPLEMENTARY-BIAS dataset — violates the project's **Strict Public-Only Dataset Policy**:

1. The dataset is hosted at `github.com/Purdue-M2/AI-Face-FairnessBench` (not `altamimi-omar/AI-Face-FairnessBench` as originally recorded).
2. Access requires a **signed End User License Agreement (EULA)** submitted via Google Form.
3. The license is **CC BY-NC-ND 4.0** (No Derivatives), which is more restrictive than anticipated.

This directly conflicts with the mandate in DEC0004: *"only datasets with open, public, zero-restriction availability and permissive licenses (MIT, CC BY, CC BY-NC) are selected."*

Additionally, the original `datasets.csv` URL `https://github.com/altamimi-omar/AI-Face-FairnessBench` returns a **404 error** — the referenced repository does not exist.

---

**Options Evaluated:**

| Option | Dataset | License | Access | Demographic Annotations | Pros | Cons |
|--------|---------|---------|--------|------------------------|------|------|
| A | **FairFace** (Karkkainen & Joo, WACV 2021) | **CC BY 4.0** | ✅ Public (GitHub + Google Drive + Kaggle) | 7 race groups, gender, age | Gold-standard fairness benchmark; 108k images; cited 400+; available on Kaggle | Real faces only (no synthetic) — but that's the correct role for bias evaluation of the *detector's performance on real faces* |
| B | Keep AI-Face-FairnessBench | CC BY-NC-ND 4.0 | ❌ EULA required | Skin tone, gender, age | Purpose-built for AI-face detection fairness | Violates Public-Only Policy; EULA blocking; ND license prevents preprocessing |
| C | Exclude bias evaluation entirely | N/A | N/A | N/A | No dependency | Sacrifices GAP0002 (bias evaluation) |

---

**Chosen Option:** **Option A — Replace DS0005 with FairFace**

### FairFace Dataset Profile
- **Full Name:** FairFace: Face Attribute Dataset for Balanced Race, Gender, and Age
- **Authors:** Karkkainen, K. & Joo, J. (WACV 2021)
- **Image Count:** 108,501 images
- **Demographic Annotations:** 7 race groups (White, Black, Indian, East Asian, Southeast Asian, Middle Eastern, Latino), binary gender, age ranges (0–2, 3–9, 10–19, 20–29, 30–39, 40–49, 50–59, 60–69, 70+)
- **License:** CC BY 4.0 (fully permissive, allows derivatives)
- **Access:** Public GitHub (`dchen236/FairFace`) with Google Drive download links; also available on Kaggle
- **Format:** 224×224 JPG images with CSV label files
- **Citations:** 400+ (gold-standard fairness benchmark in computer vision)
- **Role in Project:** SUPPLEMENTARY-BIAS — used to evaluate whether the AI Forensic Analyst's detection accuracy varies across demographic subgroups (GAP0002). The detector classifies these real faces; any false-positive disparities across demographics indicate bias.

---

**Rejected Options:**

- **Option B (Keep AI-Face-FairnessBench):** Rejected because it requires a signed EULA, contradicting the Public-Only mandate ratified in DEC0004. The CC BY-NC-ND license also forbids derivative works, preventing necessary preprocessing (resize, crop, format conversion).
- **Option C (Drop bias evaluation):** Rejected because GAP0002 (demographic bias in detection) is a core research contribution and examiners will expect fairness analysis.

---

**Reason for Chosen Option:**

1. **100% Public & Frictionless:** FairFace is immediately downloadable from GitHub/Google Drive/Kaggle with zero approval process, fully compliant with the Public-Only Policy.
2. **CC BY 4.0 License:** The most permissive Creative Commons license — allows commercial use, derivatives, and redistribution with attribution only.
3. **Gold-Standard Fairness Benchmark:** FairFace is the most widely cited face fairness dataset in computer vision (400+ citations, WACV 2021). Using it strengthens the project's credibility.
4. **Demographic Coverage:** 7 race groups + gender + age provides richer demographic analysis than AI-Face-FairnessBench's 3-axis (skin tone + gender + age).
5. **Correct Evaluation Design:** For bias evaluation, we need a balanced set of *real* faces to test whether the detector produces false positives at different rates across demographics. FairFace's 108k balanced real faces serve this role perfectly.
