# Decision: DEC0007

**Decision Status:** APPROVED (Human, 2026-11-10)
**Date:** 2026-11-10

---

**Problem:** Phase E9 needs a model that never saw the tested generator. MODEL0001 was trained on SPLIT0001, which contains all 13 generators, so it cannot answer E9. Each held-out generator needs its own training run (about 40 minutes of Kaggle T4). Separately, the FairFace test partition (21,962 images) makes the Phase E8 Kaggle run longer.

---

**Options Evaluated:**

| Option | E9 scope | Cost |
|--------|----------|------|
| A | Stable Diffusion only, using the existing `SPLIT0002` (one new experiment) | ~1 Kaggle session |
| B | Stable Diffusion plus 2–3 of the hardest generators from STEP-045 (new splits) | 3–4 sessions, new splits |
| C | All 13 generators (full leave-one-generator-out) | ~8 h of GPU over several sessions |
| D | No training now; E8 only | none, but E9 not done |

FairFace in E8: a fixed seeded sample of 10,000 images, or all 21,962.

---

**Chosen Option:** **Option A**, and a 10,000-image FairFace sample (seed 42).

**Rejected Options:** B and C for cost at this stage; D because E9 is critical in the protocol.

---

**Reason for Chosen Option:** `SPLIT0002` already exists with leakage PASS, so no new split is needed. One held-out generator gives a real unseen-generator result now. A 10,000-image sample estimates the FairFace false-positive rate within about ±1 percentage point.

---

**Expected Impact:**
- New experiment `EXP0002` / model `MODEL0008`: EXP0001's configuration with only the split and identity changed. The learning rate is EXP0001's LR Finder value (`learning_rate.source: manual`), so the held-out generator is the only training difference.
- E9 conclusions cover one generator (Stable Diffusion) and must say so.
- E8 FairFace numbers come from a sample; the sample is fixed by seed and recorded in the config.

---

**Supporting Evidence:**
- `03_Datasets/splits/DS0001_PP0001_SPLIT0002/split_config.json` (held-out generator, partition counts, leakage PASS)
- `06_Experiments/EXP0002/config.yaml`
- `08_Evaluation/EVAL0001/generalization/config.yaml` (`max_images: 10000` for DS0005)

---

**Future Review:** Revisit Option B or C after the STEP-048 comparison study if more GPU time is available.
