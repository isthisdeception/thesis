# Decision: DEC0008

**Decision Status:** APPROVED (Human, 2026-11-13)
**Date:** 2026-11-13

---

**Problem:** Phase E10 asks for question-driven ablations, each a new experiment that changes one factor of the baseline. Each costs one Kaggle training run (~40 min). The forensic modules named in E10 (evidence, confidence, explainability) do not exist yet.

---

**Options Evaluated:**

| Option | Factor | Needs new code |
|--------|--------|----------------|
| Seed replicate | `random_seed` 42 → 43 | no |
| No augmentation | `augmentations.aug_transforms.enabled` → false | no |
| No pretraining | `model.pretrained` → false | no |
| Image size 160 | `image_size`, `fastai.item_tfms.resize` → 160 | no |
| Label smoothing 0.1 | `loss_function.label_smoothing` | no |
| SGD optimizer | `optimizer.name` (+ its own LR Finder) | no |
| Degradation augmentation | new JPEG/blur/downscale training augmentation | yes |
| Evidence / confidence / explainability ablations | modules not built | — |

Organisation: one Kaggle notebook training all chosen ablations in sequence, or one notebook per ablation.

---

**Chosen Option:** seed replicate (EXP0003 / MODEL0009), no augmentation (EXP0004 / MODEL0010), no pretraining (EXP0005 / MODEL0011), image size 160 (EXP0006 / MODEL0012); one sequential Kaggle notebook.

**Rejected Options:** label smoothing, SGD, and degradation augmentation are not run now. Module ablations wait for the modules.

---

**Reason for Chosen Option:** The seed replicate gives the noise floor every other difference is read against. The other three test the main design choices of the baseline (augmentation, transfer learning, input resolution) with no new code.

---

**Expected Impact:**
- Every ablation reuses EXP0001's learning rate and schedule (`learning_rate.source: manual`), so exactly one factor changes. For no pretraining this means a short, untuned from-scratch run.
- Each experiment publishes to its own Kaggle dataset (`thesis-exp000N-artifacts`).
- The comparison (`08_Evaluation/ablations/`) is in-distribution (SPLIT0001 test) only.

---

**Supporting Evidence:** `06_Experiments/ablations/STEP048_plan.yaml`; `17_Automation/ablation/plan.py` (one-factor check); `05_Models/baseline_plan.md`.

---

**Future Review:** Degradation augmentation is the most direct follow-up to the STEP-046 robustness result and can be added as a new ablation once the training pipeline supports it.
